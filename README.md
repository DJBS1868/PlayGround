## 🍉 Melon Playground

A playable physics sandbox homage built with Canvas and [Matter.js](https://brm.io/matter-js/). Drop fruit ragdolls into a test chamber, hand them weapons, stack props, and cause controlled (and uncontrolled) chaos. All artwork and UI are original.

### Play

Open `index.html` through any static server, for example:

```bash
python3 -m http.server 3002
```

Then visit <http://localhost:3002>. On phones, rotate to landscape — the game shows a rotation prompt in portrait.

### Controls

- **HAND** — drag a melon or prop; drag empty space to pan the camera.
- **ITEMS** — open the shop, pick a category, then tap an item to equip it.
- **Tap / click the arena** — use the equipped tool (spawn a subject, swing a weapon, place a prop, trigger chaos).
- **Hold** with automatic weapons (minigun, flamer) to keep firing.
- **Mouse wheel / pinch** — zoom.
- **1–6** — select a hotbar slot.
- **Undo / Reset** — top-right HUD buttons.
- **Pause** — pause menu with resume, reset, and clear options.
- **Speaker** — mute or unmute synthesized sound effects.

### Features

- Articulated fruit ragdolls with distinct heads, expressions, and severable limbs.
- 32 items across Living, Weapons, Build, and Chaos categories.
- Melee, firearms, explosives, environmental props, and screen-wide events.
- Destructible props, particles, decals, screen shake, and audio feedback.
- Responsive landscape HUD for desktop, tablet, and phone.
